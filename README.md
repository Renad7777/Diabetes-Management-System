# 🩺 Diabetes Treatment Recommendation System(Graduatoin project)


## 📌 Overview

The **Diabetes Treatment Recommendation System** is an AI-powered healthcare project designed to help diabetes patients manage their health through personalized recommendations for nutrition and exercise.

The system analyzes patient health data such as blood sugar levels, blood pressure, cholesterol, BMI, and age to generate customized meal plans and workout recommendations that improve lifestyle and reduce diabetes complications.

---

## 🎯 Problem Statement

Many diabetes patients struggle to find personalized guidance for:

* 🥗 Healthy diet plans
* 🏃 Suitable exercise routines
* 📊 Daily health monitoring

Most available solutions provide general recommendations that may not fit individual patient conditions, leading to poor health decisions and increased complications.

## 🧠 Approach

### 🍽️ Food Recommendation System

1. Data Cleaning & Preprocessing
2. Feature Categorization
3. Applying SMOTE for balancing
4. Training Multinomial Logistic Regression
5. Meal Matching using Cosine Similarity

### 🏋️ Exercise Recommendation System

1. Handling Missing Values
2. Encoding Categorical Features
3. Feature Scaling using StandardScaler
4. XGBoost Model Training
5. Cross Validation & Feature Importance Analysis
